
## Project Introduction

As part of my **Resume Project Challenge**, I analyzed how *Bharat Herald*, a legacy Indian media house, is navigating one of its most critical transitions: declining print performance versus rising digital demand.

This project uncovers **data-backed insights** showing that the core issue is not audience interest, but **execution gaps** across digital experience, operational efficiency, and monetization.

## Project Overview

This analysis covers:

- Digital health and user behavior  
- Print efficiency and operational waste  
- City-level performance across markets  
- Advertising and monetization trends  
- Revenue efficiency and per-reader profitability  
- A strategic recovery and transformation roadmap  



# Digital Health: Strong Foundation, Execution Gaps

## Key Metrics

| Metric | Value | Insight |
|--------|--------|---------|
| **Digital Readiness** | 68.73% | Moderately prepared; optimisation required |
| **Bounce Rate** | 65.77% | High exits indicating UX + speed issues |
| **Engagement Rate** | 55.41% | Strong content performance once users stay |
| **Copies Wasted** | 12M | Approximately ₹360M annual losses |

### Summary Insight
Users want the content, but execution weaknesses *(speed, UX, workflows)* limit digital performance.

#  Five Years of Decline

# Page 11 — Strategic Imperatives

- Reduce print volume by **5–7%** → save ₹360M annually  
- Fix **65.7% bounce rate** by improving:  
  - Page speed  
  - Mobile UX  
  - Personalisation  
- Leverage **55% engaged users** with:  
  - Bookmarks  
  - Topic follows  
  - WhatsApp digests  
- Monetise Tier-2 digital markets → revenue per reader rising **30–36%**

# Page 12 — The Dual Engine Strategy

## Print Engine — Revenue Stability

## Digital Engine — Growth & Scale
